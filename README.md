# Computer Vision – 5 Projects

Welcome to my Computer Vision Projects Repository! This repository contains five computer vision projects developed using Python and related technologies.

## Projects

### 1. Leaf Segmentation and Plant Growth Monitoring
Identifies leaf regions in images to support plant growth monitoring.

### 2. Human Activity Recognition and Fall Detection
A computer vision project focused on recognizing human activities and detecting potential falls.

### 3. Face Recognition Under Real-World Conditions
Explores face recognition under different real-world conditions.

### 4. Intelligent Traffic Violation Detection
Uses computer vision and YOLO-based object detection to identify objects in traffic scenes.

### 5. Vision-Based Robotic Pick-and-Place Object Detection
Uses Python, OpenCV, and YOLO object detection to identify objects through a camera. The detected object's bounding box, class label, confidence, and center coordinates can support future robotic pick-and-place integration.

## Technologies

- Python
- OpenCV
- YOLO / Ultralytics
- Computer Vision
- Object Detection

## Repository Structure

Each project is organized in its own folder and includes relevant source code and documentation.
